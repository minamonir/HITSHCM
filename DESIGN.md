## Must-have UI states

- Loading
- Empty
- Error / retry
- Disabled / pending submit
- Success confirmation (where irreversible)

## Breakpoints to smoke

- ~375px (mobile)
- ~768px (tablet)
- ~1280px+ (desktop)

## Accessibility baseline

- Semantic HTML and labeled inputs
- Keyboard-reachable primary actions
- Visible focus; contrast good enough for body text
