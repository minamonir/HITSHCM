# Vibe research

Turn a vague idea into research notes. Do not write app code. Do not draft the full PRD yet.

## Steps

1. Read `AGENTS.md`, existing `MEMORY.md`, and any idea notes the user pasted.
2. Interview in clusters (3-5 questions per turn): users, pain, MVP usefulness, constraints, success signal, non-goals.
3. After each cluster, reflect a short summary; mark guesses as ASSUMPTION.
4. When the user says finalize (or enough is known), produce:
   - Research summary bullets
   - Open questions
   - Suggested MVP In/Out seeds
5. Offer paste-ready updates for `MEMORY.md` (do not invent product features).

## Avoid

- Jumping straight to stack or UI chrome
- Inflating scope "while we are here"
